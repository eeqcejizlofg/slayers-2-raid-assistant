## Overview

Slayers 2 Raid Assistant is a community-built companion tool for Slayers 2 that overlays real-time DPS and damage output metrics during boss encounters, tracks raid group composition and buff coverage, and provides a pre-raid checklist for gear and consumable preparation. It reads game log data to calculate encounter statistics.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Slayers 2 Raid Assistant** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **DPS Overlay** | Real-time damage-per-second display for each raid member |
| **Buff Tracker** | Monitors active raid buffs and alerts when coverage gaps appear |
| **Boss Timeline** | Records boss ability timing for post-encounter analysis and planning |
| **Gear Checklist** | Pre-raid checklist ensuring all members meet gear and consumable targets |
